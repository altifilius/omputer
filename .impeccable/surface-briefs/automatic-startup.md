# Automatic startup

Mode: Operate. Extension of the existing Dusk atelier world; no visual identity replacement.

## Job

Open PC application once, then open Android app: find the PC, compare the same short code, approve, see real projects. No terminal commands, IP address entry, JSON paste, runtime package downloads or manual project registration in the primary flow.

## Direction contract

OWN-WORLD: Existing ink/periwinkle/porcelain/citrus tokens and platform-native controls. Android remains Material3; PC uses a coherent native status window, not browser dashboard styling.
STORY: Understand whether PC preparation, discovery or device approval is pending; one action completes the current step. Security approvals identify exact device and matching code.
FIRST VIEWPORT: Android heading and discovery list leading to a code-comparison state; PC status, automatic setup progress and pending phone approval. No shell/code blocks in onboarding. Previously paired device reconnects without another setup.
